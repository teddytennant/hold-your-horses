# hold your horses

A Claude Code plugin that puts the 5 hour limit back, so you can't spend more than 10% of your weekly usage in any 5 hour window.

```sh
claude plugin marketplace add teddytennant/hold-your-horses && claude plugin install hold-your-horses@hold-your-horses
```

`/5hour on` and `/5hour off`. `/5hour on 20` sets the cap to 20%.
